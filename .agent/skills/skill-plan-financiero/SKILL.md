# Propósito

Documentar de forma prudente y trazable los supuestos económicos y financieros de Sistreg / Proyecto Logístico.

# Cuándo usarla

Usar al trabajar:
- `respuestas_plan_empresa/06_5_economico_financiero.md`
- `plan_empresa/06_5_economico_financiero.md` (solo guía)
- `anexos/A09_plan_economico_financiero.md`
- `anexos/finanzas/`

# Entradas esperadas

- Excel financiero.
- Supuestos de precios.
- Costes fijos.
- Costes variables.
- Inversión inicial.
- Escenarios de ingresos.
- Necesidades de financiación.

# Salida esperada

Plan financiero explicado con datos, hipótesis y pendientes separados.

# Reglas

- Ser conservador.
- Separar inversión, gastos, ingresos, financiación y escenarios.
- Indicar de dónde sale cada cifra.
- Diferenciar dato real, hipótesis y pendiente.
- Relacionar el Excel financiero con el texto del plan.
- No hacer proyecciones optimistas sin justificación.

# Límites

No inventar cifras ni fórmulas no verificadas.

# Verificación

Comprobar:
- supuestos documentados;
- coherencia con modelo de negocio;
- cifras principales explicadas;
- pendientes marcados.
