# Propósito

Revisar el Plan de Empresa antes de entrega para detectar contradicciones, huecos, exceso de promesas o falta de evidencia.

# Cuándo usarla

Usar antes de consolidar o entregar el documento.

# Entradas esperadas

- Archivos principales de `respuestas_plan_empresa/`.
- Archivos de `plan_empresa/` (solo como guía de contraste).
- Anexos mínimos.
- Gates de entrega.
- Registro de decisiones.

# Salida esperada

Reporte de auditoría con:
- problemas críticos;
- problemas medios;
- pendientes;
- recomendaciones;
- veredicto de avance.

# Reglas

- Revisar coherencia entre apartados.
- Confirmar que el resumen ejecutivo coincide con el plan.
- Confirmar que el financiero coincide con el modelo de negocio.
- Revisar tono.
- Verificar que se usa **Sistreg** como marca y Proyecto Logístico solo como referencia interna.
- Verificar que el servicio inicial se llama "arranque guiado" y no "piloto".
- Verificar que el diagnóstico gratuito no se cuenta como ingreso.
- Marcar como error cualquier apartado que suene a CV o informe externo.

# Regla de conservación de valor documental

La auditoría no tiene como objetivo acortar textos por defecto.

Solo se permite reducir, fusionar, mover o simplificar contenido cuando exista una razón concreta:
- duplicidad real entre apartados;
- contradicción;
- contenido fuera de lugar;
- frase conversacional;
- sección interna no apta para entrega;
- exceso de teoría sin conexión con el proyecto;
- pérdida de tono profesional;
- repetición que no añade trazabilidad, claridad ni accionabilidad.

Antes de proponer un recorte, el auditor debe indicar:
1. Qué problema corrige.
2. Qué información se conserva.
3. Qué información se elimina.
4. Por qué la eliminación no afecta la trazabilidad.
5. En qué archivo o apartado queda cubierta la información eliminada, si aplica.

Está prohibido:
- resumir por resumir;
- acortar solo por estética;
- eliminar matices estratégicos validados;
- borrar advertencias, hipótesis o pendientes relevantes;
- sustituir contenido específico por frases genéricas;
- convertir textos accionables en textos vagos;
- reducir tablas útiles si ordenan decisiones importantes;
- eliminar contexto necesario para entender una decisión.

Criterio principal:
Todo ajuste debe mejorar al menos uno de estos aspectos:
- claridad;
- coherencia;
- precisión;
- trazabilidad;
- accionabilidad;
- tono profesional;
- eliminación de duplicidad real.

Si el cambio no mejora al menos uno de esos aspectos, no debe hacerse.

# Regla de auditoría antes de edición

Primero se entrega informe de hallazgos.
Después se pide aprobación para modificar.

No se deben aplicar cambios relevantes directamente sobre archivos finales sin:
- identificar el problema;
- explicar impacto;
- proponer acción;
- recibir autorización.

Las correcciones menores de erratas pueden proponerse como cambios directos, pero cualquier recorte, fusión, reordenación o eliminación de contenido debe pasar por informe previo.

# Límites

No hacer auditoría completa si el usuario pidió revisar solo un archivo.

# Verificación

Comprobar que cada recomendación incluya:
- archivo;
- ubicación aproximada;
- problema;
- impacto;
- acción recomendada;
- riesgo de pérdida de información;
- si requiere aprobación antes de editar.
