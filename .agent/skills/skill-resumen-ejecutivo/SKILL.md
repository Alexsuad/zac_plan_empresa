# Propósito

Construir un resumen ejecutivo claro, breve y defendible para exposición y documento final.

# Cuándo usarla

Usar al trabajar `respuestas_plan_empresa/00_resumen_ejecutivo.md`.
`plan_empresa/00_resumen_ejecutivo.md` solo se consulta como guía.

# Entradas esperadas

- Idea de negocio.
- Cliente objetivo.
- Propuesta de valor.
- Mercado.
- Modelo de ingresos.
- Síntesis financiera.
- Riesgos y próximos pasos.

# Salida esperada

Resumen ejecutivo con:
- versión para exposición;
- versión para Plan de Empresa;
- datos clave;
- riesgos;
- próximos pasos.

# Reglas

- Debe poder entenderse sin leer todo el plan.
- No introducir información que no exista en el plan o anexos.
- No exagerar oportunidad ni resultados.
- Incluir problema, solución, cliente, valor, modelo, mercado, cifras, riesgos y próximos pasos.
- Mantener lenguaje claro y profesional.

# Límites

No inventar cifras financieras ni validaciones comerciales.

# Verificación

Comprobar:
- coherencia con idea, mercado y financiero;
- no promete más que el plan;
- es claro para una exposición breve.
