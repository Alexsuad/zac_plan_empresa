# Propósito

Redactar textos comerciales de Sistreg que expliquen con claridad el problema logístico, el coste del bloqueo y el entregable real que recibe el cliente.

# Rol experto logístico

El lenguaje comercial de Sistreg debe escribirse desde el criterio de un especialista en logística, cadena de suministro y mejora operativa. El texto debe usar léxico profesional, técnico y moderno del sector cuando aporte claridad, precisión o credibilidad, especialmente en logística, transporte terrestre, transporte aéreo, transporte marítimo, comercio exterior, almacenaje, compras, aprovisionamiento, suministros, filosofía Lean, control documental y operaciones B2B.

El objetivo no es llenar el texto de tecnicismos, sino demostrar dominio real del proceso logístico y explicar el problema con el lenguaje que usaría un responsable de tráfico, operaciones, administración, almacén, comercio exterior o dirección.

# Cuándo usarla

Usar al redactar o revisar:
- pitch comercial;
- propuesta de valor;
- storytelling;
- landing;
- dossier comercial;
- presentación de ventas;
- propuestas comerciales;
- casos de entrada;
- descripción de entregables;
- explicación del arranque guiado;
- documentos donde el cliente pueda preguntarse “qué recibo exactamente”.

# Regla principal

En diagnóstico, dolor y coste del problema se usa léxico logístico profundo para demostrar criterio y conocimiento del sector.
En solución, entregable, implementación y soporte se usa léxico logístico profundo combinado con léxico tecnológico superficial, concreto y orientado a comportamiento automático para explicar el valor real.

# Léxico permitido

## Logístico profundo
Las listas de términos son ejemplos orientativos, no una camisa de fuerza. Pueden usarse otros términos logísticos profesionales si encajan con el contexto, el cliente y el proceso analizado.

Usar: operación, viaje, ruta, carga, descarga, expediente, tráfico, administración, facturación, cobro, margen, CMR, POD, albarán, evidencia de entrega, incidencia, validación, tarifa, reclamación, documento pendiente, operación bloqueada, operación lista para facturar, retraso de facturación, reproceso, pérdida de margen.

## Tecnológico superficial concreto
Usar: sistema, automatización, automático, automáticamente, dashboard, detección automática, validación automática, actualización automática, aviso automático, panel, panel accesible por internet, acceso con contraseña, enlace desde el móvil, formulario sencillo, carga de evidencias, estado por operación, vista para administración, vista para tráfico, lista de viajes, soporte inicial, ajustes de automatizaciones, evolución del sistema, IA cuando aporta valor. Se permiten estas palabras porque describen comportamiento visible para el cliente.

# Léxico a evitar en primera capa comercial

Evitar (herramientas internas o detalles de construcción): Make, n8n, Python, SQL, API, webhook, backend, frontend, endpoint, servidor, base relacional, macro, script, pipeline, OCR específico, modelo de IA, prompt, embedding.

# Regla de concreción

No basta con decir “panel”, “alertas” o “formulario”.
Debe explicarse:
- qué ve el cliente;
- qué acción realiza;
- qué ocurre automáticamente;
- quién recibe el aviso;
- qué decisión puede tomar;
- qué bloqueo logístico reduce.

# Test de calidad

Antes de aprobar un texto, comprobar:

1. ¿El cliente entiende qué problema logístico se resuelve?
2. ¿El texto usa lenguaje del sector?
3. ¿El cliente entiende qué recibe exactamente?
4. ¿Se menciona automatización cuando hay comportamiento automático?
5. ¿Se evita nombrar herramientas internas?
6. ¿Se explica qué ocurre automáticamente?
7. ¿Se evita vender IA como moda?
8. ¿Se evita ocultar la tecnología hasta volverla invisible?

# Ejemplo correcto

“El cliente recibe un panel accesible por internet con contraseña, donde administración ve qué viajes están listos para facturar, cuáles siguen bloqueados y qué documento falta. El sistema actualiza automáticamente el estado cuando se carga una evidencia y envía un aviso automático a tráfico si pasan 48 horas sin CMR o POD.”

# Ejemplo incorrecto

“El cliente recibe una solución de control operativo y trazabilidad documental.”

# Regla final

Logística profunda para demostrar criterio.
Automatización visible para explicar valor.
Tecnicismos internos solo para documentación interna.
