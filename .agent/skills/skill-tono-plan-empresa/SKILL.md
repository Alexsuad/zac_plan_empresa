# Propósito

Asegurar que todos los textos del Plan de Empresa mantengan un tono claro, profesional, realista y verificable.

# Cuándo usarla

Usar al redactar, revisar o resumir cualquier apartado de `plan_empresa/` o `anexos/`.

# Entradas esperadas

- Archivo específico a revisar o redactar.
- Objetivo del apartado.
- Público objetivo del documento.

# Salida esperada

Texto claro, sobrio y defendible ante ZAC, entidades de apoyo, bancos o administración.

# Reglas

- No usar humo tecnológico.
- No hacer promesas exageradas.
- No presentar hipótesis como hechos.
- Usar lenguaje logístico entendible.
- Evitar tecnicismos innecesarios.
- Mantener tono emprendedor, profesional y prudente.
- Explicar riesgos y pendientes cuando existan.

# Límites

No inventar datos, cifras, clientes, validaciones ni fuentes.

# Verificación

Comprobar que el texto:
- se entiende sin explicación adicional;
- no exagera;
- diferencia hechos, hipótesis y pendientes;
- mantiene coherencia con el resto del plan.
