

# 6.0. Marca, comunicación y naming

## 6.0.1. Introducción

La marca, la comunicación y el naming de **Sistreg** se desarrollan como una pieza estratégica previa al plan de marketing y ventas. No se trata únicamente de elegir un nombre, un logotipo o unos colores, sino de definir cómo debe ser percibido el proyecto, qué debe transmitir, qué debe evitar y cómo debe conectar con el cliente objetivo.

Hasta ahora el proyecto se venía trabajando bajo la denominación descriptiva **Proyecto Logístico**. A partir de este apartado, se adopta **Sistreg** como nombre provisional de marca, con el objetivo de avanzar en identidad, comunicación, narrativa y activos comerciales de forma más concreta.

Sistreg se considera una marca provisional pendiente de validación legal, disponibilidad digital y contraste comercial. Por tanto, no debe interpretarse todavía como nombre definitivo ni como marca registrada.

El objetivo de este apartado es ordenar la identidad del proyecto antes de ejecutar acciones comerciales, publicar contenidos, cerrar una landing, diseñar materiales o invertir en activos profesionales de marca.

---

## 6.0.2. Identidad provisional del proyecto

El proyecto tiene actualmente dos niveles de denominación:

| Nivel              | Uso                                                                                            |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| Proyecto Logístico | Denominación interna y descriptiva del proyecto durante la elaboración del Plan de Empresa.    |
| Sistreg            | Nombre provisional de marca para desarrollar identidad, comunicación y materiales comerciales. |

La denominación **Proyecto Logístico** (referencia interna/descriptiva) permite explicar el ámbito de actividad de forma clara. Sin embargo, es demasiado genérica para construir una marca diferenciada. Por eso se adopta provisionalmente **Sistreg** como nombre de trabajo comercial.

Sistreg permite empezar a construir una identidad más concreta alrededor de:

* sistemas;
* seguimiento;
* registro;
* trazabilidad;
* control;
* validación;
* orden operativo.

También queda aclarado que **ZAC** no es ni será el nombre del proyecto. ZAC hace referencia al entorno de Zaragoza Activa y al programa de apoyo en el que se está desarrollando el Plan de Empresa.

El término **Doc-to-Cash** podrá usarse internamente como referencia técnica o conceptual, pero no será el mensaje público principal. De cara al cliente, se utilizará una expresión más clara: **control de cobro por evidencia**.

## 6.0.3. Naming y criterios de selección

El nombre provisional elegido es **Sistreg**.

Sistreg funciona como un naming mixto, cercano a una construcción inventada o compuesta. Evoca la idea de sistema, registro, seguimiento, trazabilidad y control, sin describir literalmente todo el negocio.

Esta decisión es coherente con el proyecto porque el servicio no consiste en vender logística, software genérico ni consultoría, sino en diseñar e implementar sistemas de control operativo para procesos logísticos críticos.

El nombre debe evaluarse según los siguientes criterios:

| Criterio                | Evaluación inicial                                                      |
| ----------------------- | ----------------------------------------------------------------------- |
| Memorable               | Es corto y tiene una sonoridad compacta.                                |
| Pronunciable            | Se puede leer y pronunciar fácilmente en español.                       |
| Coherente               | Evoca sistema, registro y control, conceptos alineados con el proyecto. |
| Escalable               | No limita el proyecto exclusivamente a Zaragoza ni a un único servicio. |
| Diferenciador           | Tiene identidad propia frente a nombres demasiado descriptivos.         |
| Registrable             | Pendiente de validación formal.                                         |
| Disponible digitalmente | Pendiente de validación de dominios, redes y buscadores.                |

Sistreg no debe considerarse todavía definitivo. Antes de invertir en marca, web, materiales profesionales o registro legal, será necesario validar:

* búsqueda general en Google;
* disponibilidad de dominio;
* disponibilidad o uso en redes profesionales;
* búsqueda en OEPM;
* búsqueda en EUIPO/TMview;
* posibles coincidencias o similitudes con marcas tecnológicas, logísticas o de software;
* legibilidad y comprensión por parte de potenciales clientes.

La decisión actual no cierra el naming, pero permite trabajar con una identidad más concreta que la referencia interna “Proyecto Logístico”.

## 6.0.4. Base estratégica de marca

Sistreg nace para ayudar a pequeñas y medianas empresas logísticas a recuperar control sobre procesos críticos que hoy dependen de documentos dispersos, validaciones manuales, hojas de cálculo, correos, mensajes y seguimiento informal.

La base estratégica de la marca se resume así:

| Pregunta            | Respuesta                                                                                                                   |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Qué hace            | Diseña e implementa sistemas de control operativo, trazabilidad y validación documental.                                    |
| Para quién          | Pymes logísticas, especialmente empresas de transporte y transitarios con procesos documentales intensivos.                 |
| Qué problema aborda | Falta de control entre operación, evidencia, factura y cobro.                                                               |
| Qué lo diferencia   | Combina conocimiento logístico, criterio operativo y capacidad técnica aplicada.                                            |
| Qué no es           | No es agencia de IA, SaaS estándar, consultoría logística genérica, proveedor informático generalista ni empresa logística. |

La marca debe transmitir que entiende la operación real del cliente y que no llega a imponer tecnología por moda, sino a ordenar flujos, evidencias y puntos de control donde hoy existen fricciones.

El proyecto no debe posicionarse como “tecnología avanzada para todos”, sino como una solución práctica para empresas que necesitan más control sobre procesos concretos.

## 6.0.5. Arquetipo de marca

El arquetipo principal de Sistreg es el **Sabio**.

Esto significa que la marca debe transmitir conocimiento, análisis, criterio, claridad y capacidad para entender problemas complejos. Sin embargo, el Sabio no debe expresarse de forma fría, distante o excesivamente técnica.

La identidad se complementa con dos arquetipos de apoyo:

| Arquetipo  | Función dentro de la marca                                 |
| ---------- | ---------------------------------------------------------- |
| Sabio      | Aporta análisis, claridad, método y criterio.              |
| Cuidador   | Aporta ayuda, alivio, acompañamiento y reducción de carga. |
| Gobernante | Aporta orden, estructura, control y estabilidad.           |

La combinación deseada no es un “sabio académico”, sino un **sabio práctico**: alguien que entiende el problema, lo ordena y ayuda a resolverlo sin añadir complejidad innecesaria.

La marca debe evitar estos riesgos:

* sonar demasiado técnica;
* parecer consultoría distante;
* hablar más de tecnología que de operación;
* prometer control absoluto;
* usar lenguaje difícil para impresionar;
* comunicar desde la IA o la automatización antes de explicar el problema.

El tono adecuado será profesional, claro, sobrio y facilitador.

## 6.0.6. Posicionamiento de marca

Sistreg debe posicionarse en un espacio intermedio entre logística, procesos y sistemas.

No compite como una gran suite logística ni como un ERP, TMS o WMS. Tampoco debe competir como consultora tradicional ni como agencia de automatización. Su posicionamiento debe estar en la implementación práctica de sistemas de control para problemas operativos concretos.

La estrategia competitiva será de **especialización en nicho y diferenciación operativa**.

| Estrategia          | Aplicación en Sistreg                                                                         |
| ------------------- | --------------------------------------------------------------------------------------------- |
| Liderazgo en costes | No será la estrategia principal. No se competirá por ser el proveedor más barato.             |
| Diferenciación      | Se buscará diferenciar por criterio logístico, control documental y soluciones prácticas.     |
| Especialización     | Se priorizarán pymes logísticas con bloqueos documentales, de evidencia, facturación o cobro. |

La marca debe ocupar en la mente del cliente una idea clara:

> Sistreg ayuda a controlar lo que hoy está disperso y bloquea el cierre operativo, documental y económico de la operación logística.

La promesa de marca debe ser prudente y sostenible:

> Diseñar sistemas claros de control, seguimiento y trazabilidad para reducir bloqueos documentales y mejorar el flujo operación → evidencia → factura → cobro.

No se debe prometer:

* automatización total;
* ahorro potencial (estimado tras diagnóstico);
* sustitución completa de sistemas existentes;
* eliminación absoluta de errores;
* implantaciones rápidas sin revisar procesos;
* soluciones universales para cualquier empresa.

## 6.0.7. Territorio verbal

El territorio verbal de Sistreg debe estar construido sobre palabras que transmitan control, seguimiento y trazabilidad.

Palabras clave recomendadas:

| Territorio      | Palabras                                                               |
| --------------- | ---------------------------------------------------------------------- |
| Control         | control, seguimiento, supervisión, visibilidad, orden                  |
| Logística       | operación, tráfico, expedición, entrega, documentación, incidencia     |
| Evidencia       | albarán, CMR, POD, prueba de entrega, validación, soporte documental   |
| Flujo económico | factura, cobro, bloqueo, reclamación, cierre, pendiente                |
| Sistema         | proceso, regla, integración, cuadro de control, trazabilidad, registro |
| Utilidad        | claridad, reducción de errores, menos reproceso, decisión, acción      |

Palabras o enfoques a evitar:

* IA como reclamo principal;
* transformación digital genérica;
* automatización mágica;
* software revolucionario;
* consultoría integral;
* plataforma todo en uno;
* solución universal;
* “te ahorramos miles” sin evidencia;
* lenguaje excesivamente técnico sin conexión con el problema.

La marca debe hablar primero del problema operativo y después de la solución.

Ejemplo de enfoque correcto:

> Hay operaciones realizadas que no se pueden cerrar porque falta evidencia, validación o trazabilidad. Sistreg ayuda a ver qué está bloqueado, qué falta y qué acción debe tomarse.

Ejemplo de enfoque a evitar:

> Automatizamos tu empresa logística con IA avanzada.

## 6.0.8. Narrativa de marca

La narrativa de Sistreg debe partir del conflicto real del cliente.

El cliente no busca inicialmente “más tecnología”. Busca resolver una fricción concreta: operaciones ya realizadas que siguen abiertas, documentos que no aparecen, facturas que se retrasan, incidencias sin seguimiento y cobros bloqueados por falta de evidencia.

La estructura narrativa será:

| Elemento         | Aplicación                                                                         |
| ---------------- | ---------------------------------------------------------------------------------- |
| Protagonista     | La pyme logística que necesita operar, facturar y cobrar con más control.          |
| Conflicto        | La información está dispersa y el cierre documental depende de seguimiento manual. |
| Problema externo | Faltan evidencias, validaciones o documentos para cerrar operaciones.              |
| Problema interno | Frustración, pérdida de tiempo, sensación de desorden y falta de control.          |
| Guía             | Sistreg aporta método, diagnóstico y sistema.                                      |
| Plan             | Diagnóstico gratuito → **arranque guiado** → implementación completa.                    |
| Transformación   | De seguimiento disperso a control visible y accionable.                            |
| Acción           | Solicitar diagnóstico.                                                             |

La llamada a la acción principal será:

> **Solicitar diagnóstico**

Esta llamada es clara, prudente y coherente con la fase inicial del proyecto. No promete una solución inmediata ni fuerza una venta directa. Invita a revisar si existe un problema real.

La narrativa debe mostrar que Sistreg no sustituye al cliente ni se presenta como salvador. Su papel es actuar como guía técnico-operativo que ayuda a ordenar, medir y controlar mejor.

## 6.0.9. Identidad visual

Existe una propuesta inicial de logotipo para **Sistreg**. Esta identidad visual se considera provisional y no definitiva.

El logotipo actual utiliza un símbolo geométrico con líneas internas, acompañado del nombre Sistreg en una tipografía sobria y espaciada. La propuesta transmite:

* sistema;
* estructura;
* recorrido;
* trazabilidad;
* control;
* seguimiento;
* tecnología sobria;
* profesionalidad.

El color azul oscuro comunica confianza, rigor y estabilidad. El fondo verde azulado claro aporta una sensación de calma, claridad y control.

Esta propuesta visual encaja razonablemente con los arquetipos Sabio y Gobernante. Sin embargo, todavía debe validarse frente a varios criterios:

* legibilidad en tamaños pequeños;
* uso en blanco y negro;
* uso sobre fondo claro y oscuro;
* aplicación en documentos, LinkedIn, landing y presentaciones;
* diferenciación frente a otras marcas tecnológicas;
* coherencia con un público B2B logístico;
* capacidad de transmitir cercanía además de control.

La identidad visual de la landing previa se considera **descartable** como base definitiva. Puede servir como experimento o referencia de aprendizaje, pero no debe condicionar el desarrollo final de la marca.

Por ahora, el logo de Sistreg se utilizará solo como propuesta inicial provisional.

## 6.0.10. Comunicación y canales

La comunicación de Sistreg debe estar orientada a clientes B2B logísticos que necesitan entender rápido qué problema se resuelve y por qué merece la pena hablar.

Los públicos principales serán:

| Público                               | Mensaje principal                                                                    |
| ------------------------------------- | ------------------------------------------------------------------------------------ |
| Gerencia                              | Mayor control sobre procesos que afectan facturación, cobro y rentabilidad.          |
| Operaciones / tráfico                 | Menos seguimiento manual y mayor visibilidad sobre incidencias y evidencias.         |
| Administración / facturación          | Menos bloqueos documentales y más claridad sobre qué está listo para facturar.       |
| Aliados / asociaciones                | Proyecto especializado en control operativo aplicado a pymes logísticas.             |
| Zaragoza Activa / entorno emprendedor | Proyecto B2B con foco logístico, validación progresiva y propuesta técnica aplicada. |

Los canales iniciales serán:

| Canal                          | Función                                                           |
| ------------------------------ | ----------------------------------------------------------------- |
| LinkedIn personal profesional  | Autoridad, credibilidad, contenido y prospección inteligente.     |
| Landing simple                 | Explicar la propuesta, captar interés y facilitar el diagnóstico. |
| Dossier comercial              | Apoyo para reuniones y visitas.                                   |
| Presentación breve             | Explicar problema, método y oferta inicial.                       |
| Contactos directos / visitas   | Canal principal de conversión comercial.                          |
| Networking y entorno sectorial | Apoyo para abrir conversaciones y detectar oportunidades.         |

No se priorizarán redes sociales generalistas en la fase inicial. La comunicación debe concentrarse en canales que el cliente B2B pueda valorar y que el proyecto pueda mantener con consistencia.

El criterio será:

> No estar en todas partes, sino estar donde el cliente necesita confianza, claridad y prueba de criterio.

## 6.0.14. Conclusión estratégica

Sistreg se adopta como nombre provisional para avanzar en la construcción de marca, comunicación y activos comerciales del proyecto. La decisión permite superar la denominación genérica y de referencia interna “Proyecto Logístico” y trabajar con una identidad más concreta, alineada con sistema, registro, seguimiento, control y trazabilidad.

La marca debe transmitir principalmente **control** y **seguimiento**, sin caer en lenguaje tecnológico genérico ni promesas sobredimensionadas. Su posicionamiento se basa en ayudar a pymes logísticas a ordenar procesos críticos donde la falta de evidencia, validación o trazabilidad bloquea el cierre operativo, la facturación o el cobro.

La identidad visual inicial de Sistreg es útil como punto de partida, pero no se considera definitiva. La landing anterior se toma como experimento descartable y no como base obligatoria de marca.

La estrategia de comunicación deberá ser clara, profesional y accionable. La marca debe ayudar a que el cliente entienda el problema, reconozca el valor del control operativo y dé el siguiente paso: **solicitar diagnóstico**.

En síntesis:

> Sistreg será, provisionalmente, la marca que representa un sistema de control y seguimiento para procesos logísticos críticos, orientado a convertir operaciones dispersas en evidencias trazables, decisiones claras y cierres más controlados.
